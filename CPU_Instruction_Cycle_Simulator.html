How it works

  • Fetch: The CPU gets the instruction from memory and places it in the Instruction Register (IR).
  • Decode: The control unit identifies the operation and the required data.
  • Execute: The CPU performs the operation and updates the register or memory.

Project features

  • Four selectable instructions.
  • Editable register and memory values.
  • Step-by-step and full-run modes.
  • Visual stage highlights, register display, and operation log.
