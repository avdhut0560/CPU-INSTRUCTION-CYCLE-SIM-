About the Project

The CPU Instruction Cycle Simulator is a simple, interactive web project that demonstrates how a CPU processes instructions step by step. It helps students understand the three main stages of the CPU instruction cycle: Fetch, Decode, and Execute.

Features

Fetch: The CPU takes an instruction from memory.

Decode: The CPU understands the instruction and identifies the operation to perform.

Execute: The CPU performs the operation and displays the result.

Four Instructions: Supports ADD, SUB, LOAD, and STORE.

Editable Values: Users can change the values of Register A, Register B, and memory.

Step-by-Step Simulation: Execute each stage individually using the Next Stage button.

Run All Stages: Complete the entire instruction cycle with one click.

CPU Registers: Displays the Program Counter (PC), Instruction Register (IR), Register A, Register B, and result.

Memory Display: Shows the instruction and memory values.

Operation Log: Displays the steps performed during the simulation.

Responsive Design: Provides a user-friendly interface on different screen sizes.

Technologies Used

HTML – Creates the structure of the webpage.

CSS – Designs the layout, colors, and interface.

JavaScript – Controls the simulation and instruction execution.
